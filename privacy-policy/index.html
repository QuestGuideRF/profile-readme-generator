Политика конфиденциальности

Последнее обновление: 25 апреля 2026

Эта страница объясняет, какие данные сервис собирает, как они используются и какие у вас есть права при работе с сайтом. Продолжая пользоваться приложением, вы соглашаетесь с описанными ниже правилами обработки данных.

О сервисе

Сайт «Генератор README для профиля» доступен по адресу profile-readme-generator.com. Сервис помогает создавать README для профиля GitHub и связанные материалы.

Какие данные могут собираться

  • данные, которые вы вводите вручную в интерфейсе, например имя пользователя GitHub и содержимое секций;
  • техническая информация об устройстве и браузере: IP-адрес, тип браузера, версия ОС, язык интерфейса, время посещения и действия на сайте;
  • данные файлов cookie и похожих технологий, которые помогают сохранять настройки и анализировать использование сервиса.

Как используются данные

  • для корректной работы сайта и сохранения пользовательских настроек;
  • для генерации README и отображения выбранных блоков интерфейса;
  • для аналитики, диагностики ошибок и улучшения продукта;
  • для связи с пользователем по вопросам работы сервиса.

Файлы cookie и похожие технологии

Сайт использует файлы cookie, локальное хранилище браузера и похожие механизмы. Они нужны, чтобы запоминать выбранную тему, состояние панелей, данные форм и другие пользовательские настройки.

При желании вы можете ограничить использование файлов cookie в настройках браузера, но часть функций сайта после этого может работать некорректно.

Сторонние сервисы

Сайт может использовать только технические внешние сервисы, необходимые для работы интерфейса, доставки контента и базовой диагностики ошибок. Маркетинговые интеграции не подключаются.

Хранение и защита данных

Данные хранятся столько, сколько это необходимо для работы сервиса, выполнения юридических обязательств и разрешения спорных ситуаций. Мы используем разумные технические меры защиты, но ни один способ передачи данных через интернет не может гарантировать абсолютную безопасность.

Передача данных третьим лицам

Данные могут передаваться только в объёме, необходимом для работы сайта, технической инфраструктуры, хостинга и соблюдения требований закона. Мы не продаём персональные данные пользователей как самостоятельный продукт.

Ссылки на сторонние сайты

В сервисе могут встречаться ссылки на внешние ресурсы. Мы не контролируем содержание и политику конфиденциальности таких сайтов, поэтому рекомендуем изучать их отдельно.

Данные детей

Сервис не предназначен для детей младше 13 лет. Если вы считаете, что ребёнок передал нам персональные данные, свяжитесь с нами, и мы постараемся удалить такую информацию.

Изменения политики

Мы можем обновлять эту политику. Актуальная версия всегда публикуется на этой странице с новой датой обновления.
